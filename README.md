# Alittlemovie

面向个人创作者的剧本到短剧工作台。本阶段优先支持预算有限的个人创作：角色设定提示词、剧本拆镜、逐镜静帧/动态规划、费用估算、浏览器本地草稿和 JSON 导出。

## 当前能力

- 将剧本按空行和场景标题拆分为场景及镜头（规则拆分，不是 AI 剧本模型）
- 编辑镜头描述与时长，并选择哪些镜头值得制作成动态视频
- 维护角色描述与统一画面风格，复制角色参考图提示词
- 复制静帧/视频镜头提示词，方便在用户自行选择的生成工具中使用
- 以每月 ¥100 为预算上限，记录个人已花费金额并估算已勾选动态镜头的预算
- 保存到当前浏览器 `localStorage`，或导出包含预算规划的 JSON 备份

## 预算与费用说明

月预算默认规划为：角色/场景参考图 ¥20、重点动态镜头 ¥60、重试预留 ¥20。估算单价默认为 ¥0.60/秒，仅作为可编辑的占位估算，**不是供应商实时报价或保证价格**。请在生成前核对服务商的官方价格、计费单位、模型/API 权限和地区可用性，并自行把实际花费填入“已花费”。本页面不会调用图像或视频生成 API，也不会产生生成费用。

省预算工作流：先确定角色设定和视觉风格，制作并挑选角色/背景参考图；人工检查分镜和提示词；默认用静帧、字幕、配音和免费剪辑软件完成普通镜头，只为少数动作或情绪重点镜头规划动态生成；预留资金给失败重试。角色一致性由参考图辅助，任何生成服务均不应承诺完全一致。

## 本地运行

要求 Node.js 18.17 或更高版本：

```bash
npm install
npm run dev
```

打开 http://localhost:3000。

本地草稿只保存在当前浏览器，不等同于云端保存；清理浏览器数据前请先导出备份。当前没有账号、云端存储、视频生成 API 或 MP4 合成。后续若接入生成服务，应使用服务端密钥、异步任务、成本确认/限额与可重试的任务状态，绝不把 API Key 放在前端。
